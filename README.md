# CircuitPilot AI

**An AI-assisted electronics design workbench** that interprets text and circuit images, creates a structured circuit-design specification, flags ambiguity, and exports engineering review artifacts.

## What this version does

- Accepts natural-language requirements and optional circuit images.
- Calls an OpenAI-compatible Chat Completions API.
- Validates the response against strict Pydantic models.
- Checks duplicate references and connection-reference integrity.
- Flags unverified components, assumptions and missing information.
- Exports `circuit_design.json`, `bom.csv`, and `connections.csv`.
- Can run KiCad ERC on a user-supplied `.kicad_sch` file when KiCad CLI is installed.
- Includes automated tests, structured logging, Docker packaging and deployment guidance.

## Important engineering boundary

This release does **not** automatically generate a native KiCad schematic or PCB layout from the AI specification. It does not certify electrical safety, signal integrity, thermal performance, manufacturability or regulatory compliance. The KiCad ERC action checks an actual user-supplied KiCad schematic only. A clean ERC is not proof that a design is functionally or physically correct.

See `docs/ROADMAP_TO_PRODUCTION.md` for the controlled path to native schematic generation, PCB layout, DRC, simulation and manufacturing release.

## Quick start

Python 3.11 is recommended.

### Windows PowerShell

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

### Linux

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
```

Edit `.env` with the provider's documented API base URL, secret key and exact model identifier. Never commit `.env`.

Run:

```bash
streamlit run app.py
```

Tests:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
ruff check .
```

## Configuration

| Variable | Required | Meaning | Default |
|---|---:|---|---|
| `AI_BASE_URL` | Yes | Provider API base URL | `https://generativelanguage.googleapis.com/v1beta/openai/` |
| `AI_API_KEY` | Yes | Secret Gemini API key from Google AI Studio | (None) |
| `AI_MODEL` | Yes | Exact model identifier | `gemini-3-flash-preview` |
| `KICAD_CLI_PATH` | No | Absolute path to `kicad-cli`, if not on PATH | (Auto-detected) |
| `MAX_IMAGE_MB` | No | Maximum accepted image size | `8` |
| `MAX_PROMPT_CHARS` | No | Maximum prompt length | `12000` |
| `OUTPUT_DIR` | No | Output directory | `projects` |
| `LOG_LEVEL` | No | Python logging level | `INFO` |

### Setting up Google Gemini (Default)
1. Get an API key from [Google AI Studio](https://aistudio.google.com/api-keys).
2. Set `AI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/`.
3. Set `AI_API_KEY` to your Gemini API key.
4. Set `AI_MODEL=gemini-3-flash-preview` (or another active Gemini model).

## KiCad ERC

Install KiCad 10 and verify:

```bash
kicad-cli version
kicad-cli sch erc --help
```

If the executable is not on PATH, set `KICAD_CLI_PATH` in `.env`.

In the application, upload a real `.kicad_sch` file and run ERC. The resulting report belongs to that uploaded schematic; it is not a validation report for the AI-generated JSON specification.

## Security

- `.env` is ignored by Git.
- Never put secrets in source code, prompts, screenshots or Discord.
- Uploaded images are size-limited and decoded before use.
- Output filenames are generated by the application.
- Do not upload confidential or proprietary circuit designs to a third-party AI provider without authorization.
- For public deployment, configure provider secrets in the hosting platform, not in the repository.
- Add authentication, quotas and abuse controls before exposing the service to unrestricted public traffic.
